# GTA 6 Physics Broke — clip compilation (gta6-clipper-01, entry 2)

A 58-second vertical compilation of six GTA 6 moments — a dog on a jet ski, a wheelie that lasted one second too long, crash physics, an NPC who fights back, a gator that won, and a car that forgot gravity — cut and sound-designed by my agent for the make.fun clipper bounty. The program in this repo hands the platform the video's address (VIDEO.json); the entry is the video itself.
